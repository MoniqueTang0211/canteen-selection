# 今天吃什么？— 校园食堂推荐应用

面向广东白云学院学生的午餐决策工具。选好当前身体状态（如「没胃口」「想吃辣」）、勾选想去的食堂，点「帮我选一家」即可通过弹窗获得随机推荐（含今日推荐菜、点餐方式与点餐二维码）。

> **在线体验**：<https://canteen-today.app.workbuddy.host/?sharecode=Y7MU4MAR47>
> 手机 / 电脑浏览器直接打开，无需安装。

---

## 一、功能

| 功能 | 说明 |
|---|---|
| 帮我选 | 选状态 → 选食堂 → 随机推荐，结果以居中弹窗展示（手机端无需下滑翻页） |
| 忌口过滤 | 按身体状态自动过滤匹配的店铺（如喉咙痛会跳过麻辣烫） |
| 餐厅清单 | 按食堂分组的完整店铺列表，含点餐方式标签 |
| 添加餐厅 | 应用内表单添加店铺；描述留空时自动生成推荐语 |
| 删除餐厅 | 清单页可删除自己添加的餐厅（19 家基础数据不可删） |
| 点餐二维码 | 扫码点餐的店铺展示二维码大图；图片缺失时按点餐方式显示兜底图案 |
| 中英切换 | 右上角 `中 / EN` 按钮切换全部界面文案，选择记忆在 localStorage |
| 关于 | 左下角半透明入口，弹出技术说明 |
| 主题 | 10/20–11/02 自动切换万圣节主题，也可手动切换 |

响应式：移动优先布局，触控区 ≥44px，按 WCAG AA 校准正文对比度，支持「减少动效」系统偏好。

## 二、技术栈

| 层 | 技术 |
|---|---|
| 框架 | Vue 3（Options API，本地引入 `vendor/vue.global.prod.js`，离线可用） |
| 样式 | 原生 CSS3，`style.css` 顶部集中定义设计令牌（CSS 变量），无预处理器 |
| 交互 | 原生 DOM / Vue 指令；无 UI 组件库 |
| 特效 | Canvas 2D + `requestAnimationFrame` 自绘粒子（点击爆发 + 顶部飘落） |
| 数据 | `data.js` 常量与种子数据；用户新增存 localStorage |
| 部署 | 静态托管（CDN 边缘节点），纯前端、无构建步骤 |

**用经典 `<script>` 引入，不用 ES Modules**：这样 `file://` 下双击 `index.html` 也能直接跑，不需要起服务器、不需要构建工具。

## 四、本地运行

**方式一：直接双击 `index.html`**（因为全部是经典 script，无需服务器）

**方式二：起一个静态服务**（更接近线上环境）

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 五、加一家餐厅

**① 应用内添加**：首页底部「＋ 添加餐厅」，填店名、食堂、点餐方式、菜品即可；描述留空会自动生成推荐语。数据存在当前浏览器的 localStorage 里，换设备看不到。

**② 改代码添加（所有人可见）**：编辑 `data.js` 的 `seedShops`，每个对象对应一家店：

```js
{
  canteen:   "三立园1楼",        // 所属食堂
  shopName:  "新店",             // 店名
  desc:      "一句话推荐语",      // 描述（可留空，自动生成）
  dishes:    ["菜品A", "菜品B"],  // 菜品；自选称重类可留空 []
  orderType: "现场点餐",          // 现场点单/现场点餐/扫码点餐/小程序点餐/微信扫码/可提前预定
  qrcodeImg: "img/xx.jpg"        // 可选，缺失则显示兜底图案
}
```

## 六、实现要点

**1. 推荐逻辑与界面解耦**　`app.js` 的纯函数区不碰 DOM，也不读写 Vue 状态，输入输出都是普通值：

| 函数 | 作用 |
|---|---|
| `splitInput` | 把「逗号/顿号/空格」分隔的输入切成数组 |
| `avoidHits` | 判断一家店命中了哪些忌口类型 |
| `filterByAvoid` | 按忌口类型过滤候选店池 |
| `pickRandom` | 等概率随机取一项 |
| `pickRecommendDish` | 从菜品里再筛掉忌口项，选一道推荐菜 |

因为不依赖环境，这些函数可以单独复制出来跑、也方便以后写测试。

**2. 首屏防闪（FOUC）**　`index.html` 里有一段同步执行的极小脚本，在渲染前把 `data-theme` 挂到 `<html>` 上——否则深色主题会先白闪一下再变暗。

**3. 文案集中管理**　所有界面文字收进 `data.js` 的 `I18N` 字典，模板只写 `t('key')`。加一门语言 = 加一份字典，不改模板。

**4. 粒子特效**　点击「帮我选一家」时，在点击处用 Canvas 画星星爆开，并从顶部飘落。系统开启「减少动效」时整段关闭（`prefers-reduced-motion`）。

**5. 布局**　关键容器用百分比 / Grid 切分（按钮行 48%+48%+4% 间隙、Tab 49%+49%），父容器变宽变窄时子元素等比缩放，不用一堆断点。
